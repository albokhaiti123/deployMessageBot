# 🤖 DeployMessageBot — بوت بث المحتوى الحصري

بوت تليجرام متكامل لبث المحتوى المدفوع والمجاني مع نظام دعوات وذاتية التدمير.

---

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 🔗 نظام الدعوات | كل مستخدم يمتلك رابط دعوة خاص به مع حماية من تكرار الاحتساب |
| 📨 بث المحتوى | نص / صور / فيديو / صوت / بصمة صوتية / مستندات (ألبومات حتى 10 وسائط) |
| 💰 الدفع بالنجوم | محتوى مدفوع عبر Telegram Stars ⭐ بدون أي تسريب للمحتوى قبل الدفع |
| 🔒 حماية المحتوى | منع التوجيه والنسخ (`protect_content`) |
| 💣 ذاتية التدمير | حذف تلقائي بعد فترة زمنية محددة بالثواني (تُفحص كل 15 ثانية) |
| ⏰ الجدولة | إرسال فوري، مجدول بتوقيت زمني محدد، أو متكرر |
| 🛠️ لوحة تحكم | واجهة كاملة داخل البوت للأدمن مع تدرج الصلاحيات وترقيم الرسائل |
| 📊 الإحصائيات | عدد المشتركين، الإيرادات، والرسائل المرسلة باستعلامات مجمعة سريعة |

## 🚀 التثبيت والتشغيل

### 1. استنساخ المستودع
```bash
git clone https://github.com/albokhaiti123/deployMessageBot.git
cd deployMessageBot
```

### 2. إنشاء البيئة الافتراضية
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 3. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 4. إعداد المتغيرات البيئية
```bash
cp .env.example .env
# عدّل ملف .env وأدخل القيم المطلوبة
```

### 5. تشغيل الاختبارات الآلية
```bash
pytest -v
```

### 6. تشغيل البوت

**تشغيل مباشر:**
```bash
python main.py
```

**تشغيل عبر PM2 (موصى به للإنتاج):**
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

## 🛠️ أوامر الأدمن

| الأمر | الوظيفة |
|-------|---------|
| `/admin` | فتح لوحة التحكم (خاص بالمحادثة السرية مع البوت) |
| `/cancel` | إلغاء العملية الحالية |

### خطوات إنشاء رسالة بث (ويزارد):
1. **النص / الوصف:** كتابة النص أو الضغط على تخطي
2. **الوسائط المتعددة:** إرسال صور، فيديوهات، صوتيات، بصمات، مستندات (حتى 10 وسائط) ثم الضغط على "انتهيت" أو "تخطي"
3. **نوع الوصول:** مجاني أم مدفوع بالنجوم
4. **السعر بالنجوم:** تحديد السعر (إن كان مدفوعاً)
5. **حماية المحتوى:** تفعيل أو تعطيل منع التوجيه والنسخ
6. **ذاتية التدمير:** تحديد الثواني (0 = بدون تدمير)
7. **هدف البث:** المشتركون / المجموعات / الكل
8. **الجدولة:** فوري / وقت محدد / متكرر
9. **الأزرار الشفافة:** إضافة أزرار مع التحقق من الروابط
10. **المراجعة والتأكيد:** مراجعة كافة التفاصيل وإطلاق البث في الخلفية

## ⚠️ ملاحظات مهمة

> **حماية المحتوى:** تليجرام لا يوفر API لمنع لقطة الشاشة في البوتات. `protect_content=True` يمنع التوجيه والنسخ والحفظ.

> **النجوم (Stars):** تأكد من تفعيل المدفوعات عبر @BotFather → Bot Settings → Payments.

> **قاعدة البيانات:** يستخدم SQLite مع وضع WAL والفهارس المركبة افتراضياً. للتبديل إلى PostgreSQL:
> 1. ثبّت المشغّل: `pip install psycopg2-binary`
> 2. غيّر `DATABASE_URL=postgresql://user:password@localhost:5432/dbname` في ملف `.env`.
